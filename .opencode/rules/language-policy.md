# Language Policy

Three separate language domains in this project:

1. **Agentic documentation** — ALL files that configure or instruct agents (`AGENTS.md`, `.opencode/rules/*.md`, `.opencode/commands/*.md`, `.opencode/skills/**/SKILL.md`, agent definitions, prompts) MUST be written in English.
   - Exception: report files under `.opencode/reports/` are ALWAYS written in Bahasa Indonesia (see `request-reports.md`).

2. **User communication** — all chat responses to the user MUST be in Bahasa Indonesia. Caveman ultra style applies on top of it (fragments, abbreviations), but the language stays Indonesian.

3. **Code artifacts** — code, comments, commit messages, PR titles/descriptions: normal English (standard convention).
